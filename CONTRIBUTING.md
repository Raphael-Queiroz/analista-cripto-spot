# Contributing / Contribuindo

Thanks for helping **Analista Cripto Spot** · Obrigado por contribuir.

## Ways to help / Como ajudar

- Improve `REGRAS.md`, docs, or the skill wording  
- Fix bugs or clarity in `motor_cripto.py`  
- Better tests, examples, or translations  
- Melhorar regras, docs, skill, motor, testes ou traduções  

## Process

1. Fork the repo  
2. Create a branch (`feat/...`, `fix/...`, `docs/...`)  
3. Keep changes focused  
4. Open a Pull Request with a clear description (PT and/or EN)  

## Do / Faça

- Keep **spot-only** semantics (no leverage / shorts)  
- Keep numbers **verifiable** (motor or confirmed ledger)  
- Prefer small PRs  
- Match existing style in Python / Markdown  

## Don't / Não faça

- ❌ Commit broker API keys, secrets, or `.env`  
- ❌ Commit a **live** `registro.json` with real fills  
- ❌ Add automatic order placement  
- ❌ Invent OHLCV or indicators in docs/examples presented as live data  

## Skill path

Public skill lives at `skills/analista-cripto-spot/SKILL.md`.  
Support files live under `cripto/`.
